## 📖 About the Project

**Smart Business Hub** is a lightweight, offline-first React application designed to streamline daily operations for small business owners. It replaces disjointed SaaS subscriptions by unifying your sales pipeline, email marketing, and physical inventory into a single, intuitive dashboard. 

Built for speed and privacy, all data is securely persisted in your browser's local storage—no backend required.

## ✨ Key Features

### 💼 CRM & Lead Management
*   **Kanban Pipeline:** Drag and drop leads seamlessly from *New* ➡️ *Negotiating* ➡️ *Won/Lost*.
*   **Interaction Timeline:** Log calls, emails, meetings, and internal notes with automated timestamps.
*   **Smart Linking:** Connect specific inventory SKUs directly to client profiles to track product interest.

### 📢 Marketing Automation
*   **Behavioral Triggers:** Auto-fire emails based on pipeline stage changes or prolonged lead inactivity.
*   **Dynamic Templates:** Utilize pre-built structures (Welcome, Follow-up, Promo) featuring dynamic merge tags (`{{name}}`, `{{dealValue}}`).
*   **Campaign Dashboard:** Track simulated blast metrics including total sent, open rates, and click-through performance.

### 📦 Inventory & Supply Chain
*   **Live Stock Intelligence:** Color-coded indicators for healthy (🟢), low (🟡), and critical (🔴) stock levels.
*   **Automated Reordering:** Auto-flags items dipping below minimum thresholds and calculates reorder quantities.
*   **Purchase Orders:** Track supplier orders from *Ordered* ➡️ *In Transit* ➡️ *Received*.

## 🛠️ Tech Stack

*   **Frontend:** React 19 (Single-file architecture)
*   **Styling:** Tailwind CSS
*   **Icons:** Lucide React
*   **Charts:** Recharts
*   **Database:** Browser `localStorage` (Zero-latency, offline-first)
